# 演示入口

## 建议演示顺序

1. 启动 Gradio 后询问“示例公司的年假政策是什么？”，观察请求进入知识库路径。
2. 询问“北京天气怎么样？”，观察请求进入工具 Agent。
3. 输入“我叫小林”，再问“我叫什么名字？”，观察短期记忆。
4. 上传一份不含敏感信息的 `.txt` 文件，再询问其中内容，验证索引重建。

界面会展示应用级过程摘要，包括规划类型、路由结果和工具执行状态。该摘要是系统生成的可观察轨迹，不展示模型私有推理。

## 截图状态

公开版本暂未提交真实运行截图，因为完整启动需要调用方自己的模型密钥。仓库保留了可复现的启动步骤；后续可在独立演示账号下补充不含密钥和个人信息的界面截图或短视频。
