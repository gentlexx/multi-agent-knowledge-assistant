# 架构与逻辑路线

## 组件职责

1. `MultiAgentSystem` 是统一入口，维护进程内记忆并编排规划、执行和撰写阶段。
2. `Router` 负责在知识库链与工具 Agent 之间选择路径。它先检查显式关键词，再融合 BM25 与向量相似度，最后在不确定区间调用 LLM 判断。
3. `RAGEngine` 加载文本、按 500 字符和 50 字符重叠切块，构建临时 Chroma 向量库，并取前三个相关块。
4. `AgentManager` 使用 LangGraph 的预构建 ReAct Agent 调用工具。
5. Gradio/Streamlit 只负责界面适配，不承载核心业务决策。

## 关键取舍

- 混合检索用关键词精确匹配补充语义检索，适合中文短查询，但 BM25 分数当前采用经验归一化。
- 向量库在进程启动和知识库更新时重建，部署简单，但不适合大量文档。
- 记忆只保存最近 20 轮，并向部分提示词注入最近 8 轮，控制上下文长度。
- 工具调用集中在 ReAct Agent；算术工具使用 AST 白名单，笔记工具限制在专用目录，避免执行任意表达式或路径穿越。
